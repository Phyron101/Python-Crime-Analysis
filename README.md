# Analysing Crime in Los Angeles

## Overview

This project analyses crime data from Los Angeles using Python to identify patterns in crime occurrence, locations, and victim demographics.

The analysis explores when crimes are most likely to occur, which areas experience the most crime, and the age groups most frequently affected.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Analysis

The project includes:

* Importing and exploring the crime dataset
* Extracting the hour from crime occurrence times
* Identifying the peak hour for reported crimes
* Analysing crime activity during night-time hours
* Identifying areas with the highest number of night-time crimes
* Grouping victims into age brackets
* Analysing the distribution of victim ages
* Creating visualizations to communicate findings

Python, pandas, data cleaning, data transformation, exploratory data analysis, data visualization, grouping and categorisation, and communicating insights from data.
